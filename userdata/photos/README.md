# userdata/photos/

Заготовка под изображения (аналог `~/Pictures`).

Реалистичнее остальных соседей: framebuffer у нас уже есть
(`vendor/display/console.c`), так что показать .bmp (самый простой
формат — почти сырые пиксели) — вполне посильная следующая задача,
в отличие от видео/аудио/сети. Хороший кандидат для следующей "программы".
