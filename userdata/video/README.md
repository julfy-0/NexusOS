# userdata/video/

Заготовка под пользовательские видеофайлы (аналог `~/Videos`).

Пока не функционирует: у ядра нет видеокодеков и медиаплеера. Логичное
наполнение в будущем — простой .bmp/.raw-плеер кадров или совсем
примитивный проигрыватель motion-JPEG, если вообще когда-то понадобится
видео на этой ОС. Явно не ближайший приоритет.
