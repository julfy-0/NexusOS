# userdata/apps/

Заготовка под ПОЛЬЗОВАТЕЛЬСКИЕ программы — то, что установил пользователь,
в отличие от `system/apps/`, где живут встроенные программы (`neofetch`,
`calc`, `ls` и т.д.), вкомпилированные прямо в `kernel.elf`.

Пока не функционирует по той же причине, что и весь `userdata/`: нет
user mode и нет загрузчика исполняемых файлов (загрузка — прерогатива
кольца 0, процессов не существует). Как только появятся (см. Milestone 9
в корневом README.md), сюда можно будет класть скомпилированные бинарники
и запускать их из шелла, не трогая ядро.
