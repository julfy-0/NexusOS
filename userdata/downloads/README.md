# userdata/downloads/

Заготовка под скачанные файлы (аналог `~/Downloads`).

Пока не функционирует: нет сетевого стека (ни драйвера сетевой карты,
ни TCP/IP), поэтому "скачивать" пока неоткуда. Первый реалистичный шаг —
драйвер сетевой карты (например virtio-net для QEMU — самый простой
вариант для старта) и минимальный TCP/IP стек.
