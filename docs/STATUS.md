# STATUS.md — читать первым

Этот файл — единственный источник правды о текущем состоянии NexusOS.
Если ты (человек или AI-ассистент) впервые открываешь этот проект —
прочитай этот файл целиком **до того**, как начнёшь писать код. Он
экономит часы на "переоткрытие" уже принятых решений.

Обновляй этот файл **в конце каждой рабочей сессии**, если что-то
изменилось. Это не опционально — без этого следующая сессия (твоя же,
но без памяти) начнёт блуждать.

---

## Версия

**0.1.2-genesis** (см. `docs/VERSIONING.md` за расшифровкой схемы)

## Тип ядра

Монолитное. Причина и альтернативы — `docs/adr/0001-monolithic-kernel.md`.

## Что уже работает (проверено sanity-компиляцией, НЕ живым бутом —
## реального железа/QEMU в песочнице разработки не было)

- [x] Multiboot boot-стаб (`boot/boot.S`) → `kernel_main`
- [x] GDT — плоская модель, 4 дескриптора (kernel/user code/data)
- [x] IDT + ISR — обработчики всех 32 исключений CPU
- [x] IRQ — remap PIC на векторы 32-47, диспетчер по `irq_install_handler`
- [x] VGA text-mode драйвер (80x25, скроллинг, цвета)
- [x] Serial (COM1) драйвер — параллельный лог
- [x] `kprintf` — %d %u %x %s %c %%
- [x] PS/2 keyboard driver (scan code set 1, US QWERTY, без Shift/Ctrl)
- [x] PIT timer (IRQ0, настраиваемая частота)
- [x] PMM — bitmap physical memory manager по Multiboot mmap

## Что НЕ сделано (по порядку из ROADMAP.md)

- [ ] Paging / virtual memory (следующий шаг — см. Milestone 0.2)
- [ ] kmalloc/kfree (heap ядра)
- [ ] Многозадачность / переключение задач
- [ ] Системные вызовы, ring 3 (user mode)
- [ ] Файловая система
- [ ] Драйвер диска (ATA/AHCI)

## Известные ограничения / долги

- Клавиатурная раскладка без Shift/Ctrl/Alt — только нижний регистр
- Живой бут в QEMU: первая попытка сборки на реальном кросс-компиляторе
  (`i686-elf-gcc`) вскрыла баг сборки (коллизия имён `isr.o`/`irq.o`
  между `.c` и `.S` файлами, см. CHANGELOG 0.1.1) — исправлено, но
  **успешный `make run` в QEMU ещё не подтверждён**. Это первое, что
  нужно сделать следующим шагом.
- `.note.GNU-stack` warning при линковке — косметика, не блокирует

## Следующая задача (Milestone 0.2 — Memory)

1. Подтвердить реальный бут в QEMU на твоей машине
2. Paging: включить PAE-less 32-бит paging, отобразить kernel в
   higher-half (0xC0000000) — классический hobby-OS паттерн
3. kmalloc на основе paging + PMM

Подробный план — `docs/ROADMAP.md`.
