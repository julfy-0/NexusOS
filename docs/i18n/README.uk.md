# NexusOS — Українська

NexusOS — легка 64-бітна операційна система для x86_64, написана з нуля мовою C. Використовує власний UEFI-завантажувач і freestanding-ядро.

## Можливості
- Завантаження через UEFI/GOP і framebuffer-консоль
- x86_64 long mode
- GDT, IDT, PIC, PIT та обробка винятків
- Підтримка клавіатури та миші PS/2
- Основа графічної оболонки та командний рядок
- Підтримка AHCI/FAT32
- Основа підтримки PCI та USB xHCI
- Вибір режиму завантаження: Graphic або Command Line
- Екран Kernel Panic з логами та 30-секундним зворотним відліком

## Збірка
```bash
make clean
make iso
make run
```
