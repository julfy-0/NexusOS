# NexusOS — Русский

NexusOS — лёгкая 64-битная операционная система для x86_64, написанная с нуля на C. Используется собственный UEFI-загрузчик и freestanding-ядро.

## Возможности
- Загрузка через UEFI/GOP и framebuffer-консоль
- x86_64 long mode
- GDT, IDT, PIC, PIT и обработка исключений
- Поддержка клавиатуры и мыши PS/2
- Основа графической оболочки и командная строка
- Поддержка AHCI/FAT32
- Основа поддержки PCI и USB xHCI
- Выбор режима загрузки: Graphic или Command Line
- Экран Kernel Panic с логами и 30-секундным обратным отсчётом

## Сборка
```bash
make clean
make iso
make run
```
