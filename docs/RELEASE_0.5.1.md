# NexusOS 0.5.1 — Desktop Update

NexusOS 0.5.1 introduces the first complete graphical desktop layer.

## Highlights
- New wallpaper-based desktop
- Floating dock, clock and application selection
- Nexus Menu
- Files application with VFS navigation
- Graphical Terminal
- Settings application
- Desktop Search
- Keyboard and PS/2 mouse navigation
- Existing CLI remains the primary system shell

## Build
```sh
./build.sh
# or
make clean && make iso
```

## Validation
This release was rebuilt from a clean tree with `make clean && make iso`.
