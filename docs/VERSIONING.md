# VERSIONING.md — как мы version-им NexusOS

Обычный SemVer (MAJOR.MINOR.PATCH для API) плохо подходит: у ядра ОС
нет "публичного API", которое ломается между версиями в привычном
смысле. Зато есть чёткая последовательность milestone'ов
(boot → memory → multitasking → fs → userspace → ...). Поэтому версия
привязана к ROADMAP.md, а не к произвольным изменениям.

## Формат

```
MAJOR.MINOR.PATCH-codename
```

Пример текущей версии: **0.1.0-genesis**

### MAJOR
`0` — пока система не проходит порог "самодостаточной ОС": грузится,
имеет многозадачность, файловую систему, минимальный userspace и
интерактивный shell. Переход к `1.0.0` — это отдельное решение,
зафиксированное ADR, не автоматика по чекбоксам.

### MINOR
Инкрементируется на **+1 за каждый закрытый Milestone** из
`docs/ROADMAP.md`. Т.е. MINOR = номер милстоуна. Milestone считается
закрытым, когда все его пункты выполнены И подтверждён живой бут в
QEMU (не только sanity-компиляция).

### PATCH
Инкрементируется за любое завершённое изменение **внутри** текущего
milestone, которое не закрывает его целиком: багфикс, новый мелкий
драйвер, рефакторинг без изменения поведения. Сбрасывается в 0 при
увеличении MINOR.

### codename
Каждому MINOR (то есть каждому milestone) — своё кодовое имя. Не
несёт технической нагрузки, но людям и нейронкам проще сказать
"в genesis мы это ещё не трогали", чем помнить номера. Список
кодовых имён по порядку — в конце этого файла, дополняется по мере
того как открываются новые milestone'ы.

## Где хранится текущая версия

Единственный источник правды — `docs/STATUS.md` (верхняя строка).
Дублируется в `kernel/kernel.h` (`NEXUSOS_VERSION`) — при обновлении
STATUS.md синхронизируй и это define.

## Когда обновлять что

| Событие                                      | Что меняется         |
|-----------------------------------------------|-----------------------|
| Мелкий фикс / новый драйвер внутри milestone   | PATCH +1              |
| Milestone из ROADMAP.md закрыт и забучен      | MINOR +1, PATCH → 0, новый codename |
| Система признана "самодостаточной ОС" (ADR)   | MAJOR → 1, MINOR/PATCH → 0 |

## Список кодовых имён

| MINOR | Codename | Milestone                      |
|-------|----------|----------------------------------|
| 0.1   | genesis  | Boot & Core (текущий)            |
| 0.2   | memoria  | Virtual memory, paging, heap     |
| 0.3   | threadwork | Многозадачность, планировщик   |
| 0.4   | archive  | Файловая система, драйвер диска  |
| 0.5   | descent  | Syscalls, переход в ring 3       |
| 0.6+  | (придумаем ближе к делу) | —                |
