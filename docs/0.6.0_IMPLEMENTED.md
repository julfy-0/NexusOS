# NexusOS 0.6.0 — Implemented Integration Set

This file records the parts of the 0.6.0 mega-update that are implemented in the current source tree and have passed the available static build checks.

## Process model

- Process parent PID tracking.
- Process names.
- Process priorities.
- Process start-tick accounting.
- Per-process CPU tick accounting.
- Per-process current working directory metadata.
- Per-process environment storage foundation.
- Expanded per-process file descriptor table.
- File descriptor offsets.
- VFS-backed file descriptors.
- File descriptor `open/read/write/seek/tell/close` kernel API.
- Process enumeration syscall.
- Non-blocking `waitpid`-style zombie lookup syscall.
- `exec` child-process creation path.

## Userspace ABI

- `GETPID`.
- `GETPPID`.
- `GETPRIORITY` / `SETPRIORITY`.
- `GETNAME` / `SETNAME`.
- `GETCWD` / `CHDIR`.
- `OPEN` / `READ` / `WRITE` / `CLOSE`.
- `SEEK` / `TELL`.
- `STAT`.
- `MKDIR` / `RMDIR` / `UNLINK` / `RENAME`.
- `PROCESS_ENUM` / `WAITPID` / `EXEC`.
- `MMAP` / `MUNMAP` / `BRK` foundation.

## VFS

- Absolute and relative path normalization for the new descriptor backend.
- RAM-VFS path lookup for descriptor operations.
- Mounted FAT32 read/write integration for descriptor paths.
- File size queries.
- Directory queries.
- Path-based create/write/read/rename helpers.

## Kernel stability

- Process CPU accounting is updated from normal scheduler accounting.
- Existing zombie-safe reaping remains in scheduler context.
- Private CR3 and user-memory isolation remain unchanged.
- Existing syscall Ring-3 frame validation remains unchanged.
- Existing xHCI recovery and bounded USB processing remain unchanged.

## Fonts

- Roboto Regular and Bold are embedded in `kernel.elf`.
- Roboto service reports runtime asset readiness and sizes.
- `Roboto-LICENSE.txt` is included with the project.

## Not falsely marked complete

The complete 128+ feature and 200+ hardening target remains a living scope. Features that require new protocol stacks, a full TrueType rasterizer, external runtime module loading, hardware-dependent validation, or additional scheduler/VFS architecture are not declared complete merely because their roadmap entries exist.
